# 奶龙大乱斗 · 宇宙最强龙杯 🐲

一款纯 HTML5 的横版 1v1 格斗小游戏（玩法参考《死神VS火影》），
**奶娃九形态（慈爱/暗黑/愤怒/战斗/奶龙/空虚/温柔/神龙/忧郁），每种形态一套完全不同的招式**，画风贱萌、全程搞笑。
零依赖、零构建，**双击 `index.html` 就能玩**（推荐 Chrome / Edge；立绘为可选增强，缺失时自动回退代码绘制）。

## 如何运行

- 双击 `index.html`（或双击 `启动游戏.bat`）
- 无需安装、无需联网；所有角色和音效都是代码画/合成的

## 手机游玩（触控）📱

- **打开即横屏**：竖屏打开时整屏自动旋转铺满——把手机**向左横过来**就是正的横屏画面，不需要点任何按钮；
  微信 / QQ 安卓端经 X5 元信息直接物理横屏；锁竖屏的手机也照样能玩
- **自动全屏**：支持全屏的浏览器（安卓 Chrome 等）**首次点按画面自动进全屏并锁横屏**，沉浸式开玩
- **虚拟按键**：左下方向键（◀ ▶ 移动 · ▲ 跳跃 · ▼ 防御）；右下攻击键（轻击 / 重击·远程 / 技能① / 技能②·远程 / 必杀）
- **组合技完全兼容**：按住「▲」再点「轻击」= 上挑；按住「▼」再点「轻击 / 重击」= 防反 / 背摔；双击「◀ / ▶」= 虚步
- **点选角色**：选人界面直接**点角色卡片**即可选中出战；右上角 ⏸ 暂停 · 🔊 静音 · ⛶ 全屏
- 手机端暂不支持同屏双人（选择时会提示）；电脑端不受影响（自动隐藏触控按钮，`index.html?touch=1` 可强制预览）

**组合键（参考死神VS火影，每个角色的这四招都不一样）：**

| 组合键 | 类型 | 说明 |
|---|---|---|
| **S + J** | 防反 | 带无敌帧的反击技，穿招打人（各角色有专属动作与台词） |
| **S + K** | 投技 | 近身抓取，**不可防御**，把对手甩到身后（"背摔"） |
| **W + J** | 上挑 | 对空技，把空中的对手挑飞 |
| **W + K** | 跃击 | 跃身扑击，大位移压制 |

通用键：`Enter` 确认 · `Esc` 暂停/返回 · `M` 静音 · `F1` 显示判定框（调试）

## 场地与机动

- **大地图**：战场约 2200px 宽（原来是单屏 1000px），**相机自动跟随**双人移动，拉太远时轻微拉远镜头
- **z 轴多层平台**：全场 5 块浮空草台——两侧高台 → 中台 → 中央最高台，**从下方跳穿、从上方落站、走出边缘掉落**；站得高有战术优势，但小心被上挑摘下来
- **虚步**：双击方向触发，横穿半个屏幕 + **冲刺期间完全无敌**（弹道、攻击都能穿）+ **可以直接穿过对手绕到其身后** + 一串残影；有 0.6 秒冷却
- **远程对抗**：现在双方都能隔空对轰——每个角色的 K（重击）和 U（技能）都是**专属弹道**，配合虚步闪现走位，中远距离对枪也很刺激
- **九形态立绘**：选人界面 / 标题页 / 九宫格总览展示 **逐格抠图** 的九形态立绘（`立绘/` 目录，800×800 透明 PNG）——来源为 B站视频《奶娃的各种形态》九宫格，用 rembg（u2net 模型）自动抠图 + 统一裁切；立绘缺失时自动回退代码绘制
- **对局内建模·逐形态还原**：以"奶娃"为基础骨架（头大身小），配色**按视频逐像素采样**（绿 / 黑红 / 红橙 / 深灰橙 / 金黄 / 白灰 / 粉 / 棕金 / 蓝），每个形态带**专属装饰**（头顶爱心/火焰/空洞/小花/乌云、龙角龙须、军甲护额等）与**专属远程弹道**

## 战斗系统

- **奶力值**：出招命中/挨打积攒；技能耗 25，攒满 100 放**必杀**（全屏演出）
- **连段**：每只奶龙的轻击连段段数、速度、伤害都不同（4～5 连）
- **防御**：按住防御键减伤 92%；防御中也能直接出"防反/投技"
- **受击**：击退、击飞、落地弹跳（duang~）、躺平起身、连击播报
- **弹道**：爱心飞弹、暗影弹、火焰弹、飞刀、奶瓶、回旋奶嘴、虚空环、花瓣、龙息金波、泪滴——**每个形态 K/U 两套专属远程**，各有独立弹道与特效
- **回合制**：三局两胜，99 秒倒计时，KO 慢镜头 + 胜者跳舞 + **胜利宣言**（头顶漫画气泡 + 结算面板台词）
- **耐打版平衡（v0.4）**：全员血量提升（1350~1650）；J 轻击与 K 远程重击伤害下调；技能/必杀保留威力，节奏更看重走位与抓破绽
- 全部音效为代码合成（啪 / duang / boing / 齁齁齁）

## 开发

- **造型**：整体式绘制（头身一体化轮廓 + 统一描边 + 层次光影）；"奶娃"基础骨架（头大身小）之上叠加**九形态专属配色（逐像素采样）与专属装饰**；全局建模比例 `NL.MODEL_SCALE = 0.8`（渲染与判定框同步缩放）
- **招式**：数据驱动（`js/characters.js`），动作由动作表（`js/render.js` 的 ANIMS）插值生成
- **相机/平台**：`js/util.js`（`camUpdate`/`camApply`）+ `js/stage.js`（`NL.PLATFORMS` z轴平台 + 世界层绘制）
- 代码结构：`js/util → audio → input → effects → render → characters → fighter → ai → stage → battle → main`
- 无头逻辑测试（需 Node，51 项断言，覆盖虚步/穿人/平台/相机/远程弹道）：
  ```
  node tools/smoketest.js
  ```
- 生成招式表：`node tools/gen_movelist.js`
- **立绘管线（B站视频九宫格 → 逐格抠图）**：
  - 视频信息 / 下载：`python tools/bili_probe.py BV1MqHs66E1a`（元信息+封面）· `python tools/bili_dl.py BV1MqHs66E1a`（免登录 720P）
  - 抽帧 + 九宫格裁切：`ffmpeg -i xxx.mp4 -vf fps=6 frames/f_%03d.png` → `python tools/crop_forms.py`（按字幕位置精确切除字幕带）
  - OCR 读形态名：`tools/ocr_frame.py`（复用答题速查的 RapidOCR 环境）
  - 抠图：`.venv-gfx/Scripts/python.exe tools/cutout.py 图... --model u2net`（rembg 自动去背景）
  - 定稿打包：`python tools/finalize_portraits.py`（连通域去碎片 + 裁边 + 统一 800×800 → `立绘/`）
- 一键出全部预览截图：`bash tools/shots.sh`（需要 Chrome；含立绘一览页）
- 浏览器全流程自检（Chrome 无头，自动模拟键盘 + 截图 + 轮廓连通性检查）：
  ```
  chrome --headless=new --disable-gpu --enable-logging=stderr --virtual-time-budget=22000 \
    --screenshot=out.png "file:///.../tools/browsercheck.html#navtest"
  ```
  场景参数：`#title` / `#mode` / `#select` / `#battle`（战斗快进）/ `#arena`（大地图+平台全景）/
  `#dash`（虚步残影定格）/ `#gallery`（角色图鉴+轮廓检查）/ `#navtest`（全流程键盘模拟）
